一个基于CH32V203G6U6下推式的磁悬浮
已经实现：
1. 不允许使用商用模块进行设计、开发或二次开发；设计必须基于元件进行。
2. 装置启动后，矿石能够稳定悬浮10 s以上，悬浮高度h在1.5 cm～5.0 cm之间。
3. 矿石能够稳定悬浮。稳定悬浮指矿石在水平方向偏移不超过±1 cm，竖直方向波动不超过±1 cm。
4. 测量当前悬浮高度值，并通过UART串口向裁判系统发送高度值，发送频率>10 Hz，测量误差不超过±0.5 cm。
5. 装置温度全程不得超过70℃
6. 低功耗挑战：在矿石稳定悬浮高度不小于2.5 cm的前提下，由裁判系统测量底座台的供电功率。功率越小越好。（可以达到1w以下）
   
未测试：
